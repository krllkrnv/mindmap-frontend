# Глоссарий терминов ВКР

Веб-приложение для просмотра глоссария терминов выпускной квалификационной работы с визуализацией связей между терминами в виде интерактивной ментальной карты.

## Описание проекта

Данное приложение предназначено для просмотра глоссария терминов, используемых в выпускной квалификационной работе. Основные возможности:

- **Просмотр терминов** с их определениями и категориями
- **Поиск и фильтрация** терминов
- **Интерактивная визуализация** связей между терминами в виде графа
- **Категоризация** терминов
- **Связанные термины** для построения связей в графе

Термины хранятся непосредственно во фронтенде в файле `src/data/terms.json`.

## Технологический стек

### Frontend
- **Vue.js 3** - прогрессивный JavaScript фреймворк
- **Vue Router 4** - маршрутизация для SPA
- **D3.js** - библиотека для создания интерактивных визуализаций
- **Vite** - быстрый инструмент сборки

### Развертывание
- **Docker** - контейнеризация приложения
- **Nginx** - веб-сервер для раздачи статических файлов

## Установка и запуск

### Предварительные требования

- **Node.js** версии 16.0+
- **Git** для клонирования репозитория

### 1. Клонирование репозитория

```bash
git clone https://github.com/krllkrnv/mindmap-vkr.git
cd mindmap-vkr
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`

### 4. Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`

### 5. Предварительный просмотр сборки

```bash
npm run preview
```

## Развертывание с Docker

### Вариант 1: Использование Docker Compose (рекомендуется)

1. **Сборка и запуск контейнера:**

```bash
docker-compose up -d
```

2. **Приложение будет доступно по адресу:** `http://localhost:8080`

3. **Остановка контейнера:**

```bash
docker-compose down
```

### Вариант 2: Использование Docker напрямую

1. **Сборка образа:**

```bash
docker build -t mindmap-vkr .
```

2. **Запуск контейнера:**

```bash
docker run -d -p 8080:80 --name mindmap-vkr mindmap-vkr
```

3. **Приложение будет доступно по адресу:** `http://localhost:8080`

4. **Остановка контейнера:**

```bash
docker stop mindmap-vkr
docker rm mindmap-vkr
```

### Обоснование выбора формата контейнера

Выбран стандартный формат **Docker** по следующим причинам:

1. **Универсальность**: Docker является наиболее распространенным форматом контейнеризации, поддерживается всеми основными облачными платформами
2. **Совместимость**: Работает на всех основных операционных системах (Linux, Windows, macOS)
3. **Отечественные решения**: Docker совместим с отечественными платформами:
   - **Yandex Cloud** - полная поддержка Docker контейнеров
   - **VK Cloud** (бывший Mail.ru Cloud Solutions) - поддержка Docker
   - **Selectel** - поддержка Docker контейнеров
   - **Ростелеком Cloud** - поддержка Docker
4. **Простота развертывания**: Легко интегрируется в CI/CD пайплайны
5. **Многоэтапная сборка**: Использование multi-stage build позволяет создать минимальный образ

### Пошаговые инструкции по получению доступа

#### Локальное развертывание

1. Убедитесь, что Docker установлен на вашей системе
2. Выполните команду `docker-compose up -d` в корне проекта
3. Откройте браузер и перейдите по адресу `http://localhost:8080`

#### Развертывание на сервере

1. Скопируйте проект на сервер (через git clone или scp)
2. На сервере выполните `docker-compose up -d`
3. Приложение будет доступно по адресу сервера на порту 8080
4. Для использования стандартного порта 80, измените в `docker-compose.yml`:
   ```yaml
   ports:
     - "80:80"
   ```

## Функциональность

### Основные возможности

1. **Просмотр терминов:**
   - Отображение списка всех терминов
   - Просмотр определений и категорий
   - Отображение связанных терминов

2. **Поиск и фильтрация:**
   - Поиск по названию термина
   - Поиск по определению
   - Поиск по категории

3. **Визуализация связей:**
   - Интерактивная ментальная карта (граф связей)
   - Drag & drop для перемещения узлов
   - Зум и панорамирование
   - Tooltip с информацией о терминах при наведении
   - Визуализация связей между терминами

4. **Пользовательский интерфейс:**
   - Адаптивный дизайн
   - Интуитивная навигация
   - Быстрая загрузка (данные встроены в приложение)

### Технические особенности

- **SPA (Single Page Application)** - быстрая навигация без перезагрузки
- **Локальное хранение данных** - термины хранятся в JSON файле во фронтенде
- **Responsive Design** - адаптация под разные устройства
- **Оптимизированная сборка** - использование Vite для быстрой сборки
- **Docker контейнеризация** - легкое развертывание на любой платформе
